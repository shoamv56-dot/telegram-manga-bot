# Telegram Manga Bot

بوت Telegram خاص بالمشرف للبحث عن المانجا وتنزيل الفصول.

## الميزات
- 🔵 سوات
- 🔷 ازورا
- 🟣 تيم اكس
- 🟢 مانجاليك
- MangaDex ضمن البحث العام
- 📄 تنزيل PDF مضغوط
- 🗜️ تنزيل CBZ
- 📦 حزم 1-30 و31-60 وغيرها + آخر 30 + نطاق مخصص
- 🎨 جودة خفيفة/متوسطة/عالية، والمتوسطة افتراضية
- ⭐ مفضلة و🔔 متابعة و📥 سجل التنزيلات
- ⚙️ إعدادات نوع الملف والجودة
- 👁️ رابط قراءة مباشرة للفصل
- 👑 لوحة مشرف
- 🧹 حذف الملفات المؤقتة بعد الإرسال

## التشغيل
1. ثبّت Python 3.11+ والمكتبات من `requirements.txt`.
2. انسخ `.env.example` إلى `.env`.
3. ضع `BOT_TOKEN` و`ADMIN_CHAT_ID`.
4. شغّل: `python main.py`.

## الأمان
لا تضع BOT_TOKEN في GitHub أو ترسله في المحادثات. إذا انكشف التوكن، ألغِه وأنشئ توكنًا جديدًا من BotFather.

## ملاحظات
- Telegram يفرض حدودًا على حجم الملفات؛ إذا تجاوز الملف الحد، استخدم جودة أقل أو حزمة أصغر.
- CBZ عبارة عن ZIP للصور المضغوطة، وتُحفظ حدود الفصول داخل الحزمة عند تنزيل عدة فصول.
- مواقع الويب قد تغيّر HTML؛ عندها قد تحتاج محددات scraper إلى تحديث.
- `curl_cffi` لتحسين توافق طلبات HTTP مع المتصفحات، وليس لتجاوز CAPTCHA أو أنظمة الوصول.
